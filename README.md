# 3-Digit Bionic Hand (Open-Source CAD Project)

A 3-digit bionic hand model (thumb and two fingers) designed in Autodesk Inventor. The model features independent rotational joints for each digit, internal wiring/tendon channels, and a modular claw-grip configuration optimized for 3D printing and DIY prosthetics or robotics.

---

## Features
* **Independent Articulation:** Separate rotational joints for the thumb and two fingers, allowing for varied grip patterns.
* **Internal Routing Channels:** Integrated holes and pathways designed for clean tendon/wiring management.
* **Claw-Grip Architecture:** Compact palm structure with optimized finger placement for object manipulation.
* **Inventor Native:** Built with flexible joint definitions ready for motion simulation and drive testing.
